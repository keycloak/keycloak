= Security and Standards

== Credential ID in credential update events

The `UPDATE_CREDENTIAL` events emitted by built-in required actions now carry the `credential_id` detail when a credential was created or updated in the {project_name} credential store, as the `REMOVE_CREDENTIAL` event already did. The detail is omitted when an external user-storage provider handles the update because there is no {project_name} credential ID to report.

= Identity Brokering

== Claim to Groups and Roles identity provider mapper

The new *Claim to Groups and Roles* mapper for OpenID Connect identity providers maps a claim holding delimited entries, such as `acme,admin,active`, to memberships of subgroups of a parent group and to roles from a lookup table. Missing subgroups are created, and with the *force* sync mode the mapper removes memberships and roles the claim no longer grants. Previously, each group or role needed its own mapper, and groups could not be created from a claim.

For more details, see the link:{adminguide_link}#_claim_to_groups_and_roles_mapper[{adminguide_name}].
