= Security and Standards

== Credential ID in credential update events

The `UPDATE_CREDENTIAL` events emitted by built-in required actions now carry the `credential_id` detail when a credential was created or updated in the {project_name} credential store, as the `REMOVE_CREDENTIAL` event already did. The detail is omitted when an external user-storage provider handles the update because there is no {project_name} credential ID to report.

= Extension Development

== Extend the Admin Console with the Declarative UI SPI (supported)
// https://github.com/keycloak/keycloak/issues/54149

Adding configuration screens to the Admin Console previously required maintaining a custom React theme for even simple provider forms.
The Declarative UI SPI lets extensions describe Admin Console pages and tabs in Java with `UiPageProvider` and `UiTabProvider`, and {project_name} renders those forms automatically.

In this release, the `declarative-ui` feature is promoted from experimental to supported and is enabled by default.

For more details, see the link:{ui_customization_guide_link}declarative-ui[Extending the Admin Console with the Declarative UI SPI] guide.
