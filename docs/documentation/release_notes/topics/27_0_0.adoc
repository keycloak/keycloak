= Security and Standards

== Credential ID in credential update events

The `UPDATE_CREDENTIAL` events emitted by built-in required actions now carry the `credential_id` detail when a credential was created or updated in the {project_name} credential store, as the `REMOVE_CREDENTIAL` event already did. The detail is omitted when an external user-storage provider handles the update because there is no {project_name} credential ID to report.

= Transactional outbox

== Outbox shared by multiple consumers

The generic transactional outbox that backs the push delivery of the experimental SSF transmitter can now be shared by several consumers, such as an outbound SCIM provisioning extension.
Every consumer's drainer holds its own cluster lock, deliveries run outside of database transactions under a per-entry lease, different destinations are delivered in parallel with a per-destination batch cap, and a generic Micrometer listener publishes `keycloak.outbox.*` meters.
The `OUTBOX_ENTRY` timestamps are converted to epoch milliseconds; see the upgrading guide.
