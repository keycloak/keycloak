== Breaking changes

Breaking changes are identified as those that might require changes for existing users to their configurations or applications.
In minor or patch releases, {project_name} will only introduce breaking changes to fix bugs.

=== Client scope management restored for per-client delegated administrators
// https://github.com/keycloak/keycloak/issues/54002

The additional client scope permission checks introduced for CVE-2026-14614 have been removed from client scope assignment endpoints.
Those checks incorrectly restricted the intended delegated client administration model and prevented administrators from managing scope assignments for their clients.

With Fine-Grained Admin Permissions (FGAP), a per-client `view` permission allows an administrator to see the scopes assigned to that client, including their descriptions and dynamic-scope indicators.
A per-client `manage` permission allows assigning any existing realm client scope to that client, removing assignments, and changing the assigned type (default ↔ optional).
Global `manage-clients` or type-level Clients `manage` permission is no longer required for these operations.
In FGAP v2, `manage` does not imply `view`; grant both permissions to manage scope assignments through the Admin Console.

The Admin Console obtains summaries of available scopes from `GET .../clients/\{id}/available-client-scopes`, which requires `manage` permission on that client.
This does not grant access to protocol mapper configurations, other scope attributes, or permission to edit shared client scope definitions.
The realm-wide client scope catalog retains its existing permissions.

Grant per-client `manage` only to administrators trusted to assign any existing realm client scope to that client, including the scope's protocol mappers and role scope mappings.
This change does not introduce restrictions on which scopes a delegated administrator may assign.
