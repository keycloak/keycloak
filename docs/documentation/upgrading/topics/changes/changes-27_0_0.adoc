== Notable changes

Notable changes may include internal behavior changes that prevent common misconfigurations, bugs that are fixed, or changes to simplify running {project_name}.
It also lists significant changes to internal APIs.

=== Semicolons are no longer treated as query parameter delimiters

Previously {project_name} treated the semicolon (`;`) as a query parameter delimiter in addition to the ampersand (`&`), so a request such as `/path?a=1;b=2` was parsed as two parameters.
Because different layers of the server applied this rule inconsistently, the parameters used to process a request could differ from those used to verify its signature.
{project_name} now treats the semicolon as a literal character, so the same request yields a single parameter, and this matches the default that Quarkus adopts in its next major release.
If any of your clients rely on the semicolon as a query parameter delimiter, update them to use the ampersand instead.
