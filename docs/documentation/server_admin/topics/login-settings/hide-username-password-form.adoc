== Hiding the username and password form

If a realm authenticates users exclusively through identity providers, you can hide the username and password form on the login page so that only the configured identity providers are offered. The form is shown by default.

.Procedure
. Click *Realm settings* in the menu.
. Click the *Login* tab.
. Toggle the *Username/password form* switch to *Off*.

When this setting is disabled, the login page no longer renders the username and password fields; only the configured identity provider buttons appear.

[WARNING]
=====
Make sure at least one identity provider is available to users before you hide the form. If the form is hidden and no identity provider can be used, users are unable to sign in. Keep an administrative login path available (for example, a separate realm or an identity provider that administrators can use) to avoid locking yourself out.
=====
