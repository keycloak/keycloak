== Prerequisites

The Admin API v2 requires the `client-admin-api:v2` feature:

<@kc.start parameters="--features=client-admin-api:v2"/>

== Client Setup

=== Java

Add the dependency to your project:

[source,xml]
----
<dependency>
    <groupId>org.keycloak</groupId>
    <artifactId>keycloak-admin-client</artifactId>
</dependency>
----

[source,java]
----
import org.keycloak.admin.client.Keycloak;

Keycloak adminClient = Keycloak.getInstance("http://localhost:8080", "master", "admin", "password", "admin-cli");
----

=== JavaScript

[source,bash]
----
npm install @keycloak/keycloak-admin-client
----

[source,javascript]
----
import KcAdminClient from "@keycloak/keycloak-admin-client";

const kcAdminClient = new KcAdminClient({ baseUrl: "http://localhost:8080", enableExperimentalApis: true });
await kcAdminClient.auth({ username: "admin", password: "admin", grantType: "password", clientId: "admin-cli" });
----

=== CLI

The Admin API v2 uses the same CLI tool described in the {adminguide_link}#admin-cli[{adminguide_name}] with the `--v2` flag:

<@kc.admin parameters="--v2 config credentials --server http://localhost:8080 --realm master --user admin"/>

== Error Handling

All error responses from Admin API v2 endpoints return the standard RFC 9457 `application/problem+json` media type.
Error responses follow a structured JSON schema:

[source,json]
----
{
  "type": "urn:keycloak:admin-api:v2:problem:validation-failed",
  "title": "Validation failed",
  "status": 400,
  "detail": "Provided data is invalid",
  "violations": [
    {
      "field": "clientId",
      "message": "must not be blank"
    }
  ]
}
----

=== Problem Detail Fields

* `type`: A URI reference in the `urn:keycloak:admin-api:v2:problem:` namespace identifying the specific error condition. Clients should branch on this identifier.
* `title`: A short, human-readable summary of the problem type.
* `status`: The HTTP status code generated by the origin server.
* `detail`: A human-readable explanation specific to this occurrence of the problem.
* `violations`: An array of validation errors (only present when `type` is `validation-failed`). Each entry contains a `message` and, when the error belongs to a single field, a `field`. The `field` is the path of the invalid property in the request body, or the name of the invalid query parameter, such as `offset`, `limit`, `sort`, `fields` or `q`.

=== Problem Types

|===
| Status | Type Identifier | Description

| 400
| `urn:keycloak:admin-api:v2:problem:validation-failed`
| The request contains input that is not acceptable: bean validation constraints, unknown fields, an unsupported protocol, a protocol change, a path identifier that does not match the payload, a role that does not exist, a client configuration rejected by the model validation, or an invalid `offset`, `limit`, `sort`, `fields` or `q` query parameter. Contains `violations`.

| 400
| `urn:keycloak:admin-api:v2:problem:malformed-body`
| Request body is empty, not valid JSON, or contains mismatched data types.

| 400
| `urn:keycloak:admin-api:v2:problem:invalid-patch`
| JSON Merge Patch document is invalid, not an object, or contains invalid patch values.

| 400
| `urn:keycloak:admin-api:v2:problem:policy-violation`
| Operation was rejected by a client policy executor.

| 401
| `urn:keycloak:admin-api:v2:problem:unauthenticated`
| Authentication required or token is invalid. Response includes `WWW-Authenticate: Bearer` challenge header.

| 403
| `urn:keycloak:admin-api:v2:problem:forbidden`
| Caller lacks the required administrative permissions.

| 404
| `urn:keycloak:admin-api:v2:problem:not-found`
| The realm, the client, or the endpoint path does not exist. The `detail` says which.

| 404
| `urn:keycloak:admin-api:v2:problem:api-unavailable`
| Admin API v2 feature is disabled.

| 405
| `urn:keycloak:admin-api:v2:problem:method-not-allowed`
| HTTP method is not supported on the target resource.

| 409
| `urn:keycloak:admin-api:v2:problem:conflict`
| The request conflicts with the state of a resource: the client ID or UUID is already in use, or a built-in client cannot be deleted. The `detail` says which.

| 415
| `urn:keycloak:admin-api:v2:problem:unsupported-media-type`
| Request `Content-Type` is not supported for the endpoint.

| 500
| `urn:keycloak:admin-api:v2:problem:internal-error`
| An unexpected server error occurred. Internal exception details are not exposed in the response.
|===

Any HTTP status without an explicit catalogue entry falls back to `urn:keycloak:admin-api:v2:problem:http-<status>`.
